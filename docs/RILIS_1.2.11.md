# Rilis 1.2.11

Ringkasan posisi MT5 dipindah ke tengah baris HSH/Acuan Sesi di atas tabel: jumlah posisi, jumlah BUY/SELL dan profit sesuai mata uang akun. Rincian dibuka melalui klik, menggunakan dialog di luar elemen summary agar tidak membuka rincian sesi. Tidak ada lagi panel posisi di bawah matriks. Pada layar kecil ringkasan tetap terpusat dan membungkus seperlunya. Aturan akun/server dan kesegaran tetap berlaku.
