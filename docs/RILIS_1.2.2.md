# COP TAH Windows 1.2.2

Paket Windows ini memuat perbaikan tabel hingga 20 Oktober 2026: countdown timeframe,
penanda pergerakan, baris yang mengikuti isi, prioritas SUP KUAT/RES KUAT, serta
pantauan support dengan arah sentuhan, konfirmasi 60 detik dan pembatalan area.

Node dan Python/MT5 bridge disertakan. Data akun dan arsip harga mentah tidak
ikut dibundel. Laporan pengujian 10 tahun disertakan sebagai dokumentasi.

Sebelum memperbarui, keluar melalui ikon COP TAH di area notifikasi Windows.
Jalankan installer baru lalu buka kembali aplikasi. Pengaturan browser tetap
menggunakan penyimpanan lokal yang sudah ada. Nomor versi terdaftar: 1.2.2.

Validasi paket: build frontend, impor runtime Python terbundel, sintaks backend,
pemeriksaan launcher, verifikasi payload installer dan checksum SHA-256.
