# COP TAH 1.2.4 — kekuatan relatif setiap timeframe

SUP KUAT / RES KUAT sekarang dinilai pada semua kolom dan penanda Terminal.
Rincian level menampilkan acuan serta alasan tiap syarat. Label kuat tetap
mendapat prioritas ketika ada banyak penanda pada sel.

| Timeframe | Pivot pembanding |
|---|---|
| M1–H1 | H4 |
| H4 / Market | Daily |
| Daily / Week | Month |
| Month | Quarter |
| Quarter | Semester |
| Semester | Year |
| Year | Dekade, jika pembanding lengkap tersedia |

Support: keluarga S/Pivot, di bawah harga, di atas Pivot pembanding dan Low B
milik timeframe tersebut. Resistance: keluarga R/Pivot, di atas harga, di bawah
Pivot pembanding dan High B timeframe tersebut. Sama pada presisi instrumen
bukan di atas/di bawah. Periode dan pembanding wajib aktif serta harga segar.

Aturan Daily tidak berubah. Perluasan lintas timeframe adalah aturan relatif
versi aplikasi dan belum membuktikan kekuatan prediksi pada semua timeframe.
Label kuat bukan STRONG BUY/SELL dan bukan bukti pantulan atau entry transaksi.
Year menahan penilaian jika Dekade B parsial, tidak memakai arsip campuran sebagai
pembanding lengkap. Bridge meminta hingga 240 MN1; ketersediaan mengikuti broker.

Validasi: pemeriksaan simetri support/resistance seluruh 13 timeframe, data
pembanding hilang/kedaluwarsa, kompatibilitas Daily, acuan Dekade terpisah,
dan render label kuat pada Daily serta M1. Installer membawa perbaikan ini.
